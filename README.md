# Truee

A modern AI chatbot with a calm, distraction-free interface.
Built with Next.js, NextAuth, and support for Google / GitHub / email login.

![Truee](https://github.com/Utkarsh9721/certificates/blob/main/truee.png?raw=true)

---

## What is Truee?

Truee is a chatbot web app that lets you:

- Sign in with **Google**, **GitHub**, or **email + password**
- Chat with an AI assistant in a clean, minimal UI
- Use it on desktop or mobile
- Switch between light and dark mode automatically

---

## Features

- 🔐 **Multiple login options** — Google, GitHub, and credentials
- 🌗 **Light & dark mode** out of the box
- 📱 **Responsive design** — works on phone, tablet, desktop
- ⚡ **Fast** — built on Next.js App Router
- 🎨 **Custom theme** — warm `#c96442` accent, serif headings
- 🔒 **Secure sessions** via NextAuth
